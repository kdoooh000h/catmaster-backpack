# 合成订单查询

应用 Jev 选中的 `sql-database-assistant` 指导和其 LEFT JOIN 参考，实际在新建的
本地演示 SQLite 数据库运行 `query.sql`，参数为 `status=paid`。

| 客户 ID | 客户 | 已支付金额（分） |
|---:|---|---:|
| 1 | 北星 | 1500 |
| 2 | 岚 | 700 |
| 3 | 青叶 | 0 |

先保留全部客户，再只连接已支付订单。支付条件放在 JOIN 中，避免 WHERE 把
没有匹配订单的客户过滤掉；SUM 聚合，COALESCE 把空和变为零。金额使用整数分，
按金额降序、客户 ID 升序排序。

查询通过只读连接执行；结果与预先定义的金额独立核对一致，查询前后数据库文件
哈希相同。还实际运行了原始 query optimizer 和 EXPLAIN QUERY PLAN。
优化器提示没有 LIMIT；本题明确要求返回演示表里的全部三个客户，因此保留完整
结果。该提示不等同于性能缺陷，未将小表检查说成生产数据库性能验证。
