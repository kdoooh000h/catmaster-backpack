  Its exact cause was not recorded; it remains unclassified.
- Two early plugin preparations stopped at candidate limits. The first lacked
  publisher grouping; the second encountered the publisher's 123-entry development
  category. Grouping and an explicit 192-entry leaf bound resolved this sample.
  No candidate was silently discarded.
- An unbound Skill request selected the same-name Skill from `anthropics/skills`,
  not the newly connected plugin. This did not establish plugin provenance.
  `market_selection` now binds the subsequent Jev choice to that connected package.
- The first reference MCP acquisition failed after 37.266 s during cold dependency
  download. The npm log was still downloading packages near the shared client's
  30-second startup deadline. There were zero reference tool-call receipts then.
  Dependency setup now precedes protocol startup. The later setup used a partially
  populated cache, so its time is not a clean cold-start benchmark.
- Broad Context7 registry requests abstained at 0.52 and 0.59 under the 0.7 threshold.
  The actual results included the official provider, a fork and a paid wrapper.
  A publisher-specific query selected the official `io.github.upstash/context7`
  at confidence 0.96. These abstentions are not counted as successful automatic
  routing. No threshold was lowered to make the test pass.
- Native App login, hooks, arbitrary local plugin scripts, external-repository
  plugin packages, credentials and universal marketplace compatibility are not
  established by these samples. Unsupported components return setup requirements.
- Token totals, USD cost and the underlying remote Jev model are unobservable in
  this record. Do not infer them from elapsed time or result confidence.
