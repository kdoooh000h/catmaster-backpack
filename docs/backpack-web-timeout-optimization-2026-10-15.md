# 网页超时与主 Agent 消耗续测

只续测原六题中剩下的弹簧网页题，未重跑此前通过的五题。普通需求、测试策略、CLI、`gpt-6-astra / xhigh`、360 秒上限、公开目录快照和初始 70 条分类缓存保持一致。新一轮没有提供任何能力名称，也没有复制此前安装好的插件、授权或业务结果。

本轮原生 Agent 在 **286.780 秒正常结束**，原轮在 360.010 秒被终止。网页完成了公式及模拟交互检查，但实际浏览器不可用，且原生使用记录需要测试者修复，因此**不能报告严格全流程全部通过，也不能报告六题当前版本全绿**。

## 先做的低成本检查

旧网页题的背包等待合计只有 8.178 秒。完整 Skill 和模板约在第 51.5 秒到达，HTML 在第 262.7 秒落盘，检查脚本及额外说明在第 348.5 秒落盘。文件写入本身只需毫秒；长间隔发生在生成、传输和客户端等待期间，不能全部称为思考时间。

选中插件的完整指导包含预设、额外输出布局等通用要求；旧产物实际增加了动画、曲线和四套预设。旧范围提示仅随绑定 Skill 返回，模板返回时没有提示。工具结果未同时重复发送文本和 structuredContent，可排除此种整份结果重复。旧轮采用 ephemeral，原生 SQLite 日志和线程表均为空，不能追回主 Agent token，也不能把缺失数值当零。

只读复核已通过的两项 MCP 记录，主 Agent 输入 token 分别有 93.43% 和 91.41% 命中缓存。这些输入在多次请求中累计统计，解释了“大量 token”中的一部分，但缓存不是免费，也不能据此推算货币费用。没有重跑两项 MCP。

## 修改

- Skill 和资源入口共用任务范围说明，同时出现在工具描述和选中结果里：完整阅读指导，以用户交付物为范围，按需采用方法，保留运行前提和安全、正确性检查；不自动把通用功能清单变成额外需求。完整正文、模板、目录和最终置信度门槛没有裁剪或降低。
- 测试器可选择保留隔离会话用量。只提取原生线程的累计 token 计数；重复通知、缓存与推理子集不重复相加。未完成请求仍可能缺失，超时记录仍只能提供下界。原始会话仅在仓库外的私有证据目录保留。
- 本次收尾暴露摘要 505 字符超过现有 500 字符限制。原 schema 已有上限，校验正确；问题是错误过于笼统。现返回明确的未写入状态和只修摘要的恢复方式，不静默截断，不重做任务。

本轮比旧超时点早 73.230 秒，HTML 少 31.04%。Jev 消耗基本不变。旧轮主 Agent 用量缺失，**没有依据给出 token 降幅**。这是一组单次样本，不能把全部时间差归因于提示变化，也不能证明对其他任务普遍有效。

新轮主 Agent 的 10 次用量更新累计：输入 191,066，其中缓存 163,456，非缓存 27,610；输出 8,965，其中推理 1,853 是输出的子集。不能把这些子集再加一遍。每次请求输入由 12,057 增到 26,853；生成网页的请求输出 4,706，生成检查及修正的请求输出 2,265，两者约占输出总量 77.8%。主要可优化部分仍是生成内容和往返轮数，不能仅凭 `xhigh` 设置断言瓶颈全在推理。

页面仍包含动画和曲线，范围提示只减少了部分扩张，不能充当硬限制。本轮没有切换模型或推理档位；降低档位的影响尚未对照验证。

## 验证与边界

原生 Agent 自己选择、安装了基线中不存在的公开插件，读完 Skill 和模板，生成离线 HTML。它用 Node VM 执行实际页面脚本，检查 25 组参数、四倍质量/刚度关系、单位、滑块回调、重置、动画、JSON 复制成功/拒绝/缺失时的行为，全部通过。这里的 DOM 和剪贴板为模拟对象，不是真实浏览器验收。

浏览器能力查询返回 none，`open index.html` 返回没有兼容应用，实际渲染、拖动和系统剪贴板未验证。没有通过其他浏览器或地址绕过先前文件 URL 限制。

原生 Agent 如实结束并报告使用记录失败。测试者确认旧摘要未写入后，以同一 selection/event/run 提交 385 字符摘要，保留浏览器限制，真实存储返回 recorded；没有新增模型请求、重新安装或重新执行网页任务。这个修复明确记录为测试者补交，不改写原生成功率。更明确的错误恢复路径也用原始 505 字符参数验证了无写入拒绝；自主恢复尚未另跑原生测试。

174 项相关本地测试通过；所需包装文件、目录 JSON 和 diff 检查通过。测试使用的临时 MCP 服务已核对身份、停止并确认进程退出。六个受保护配置文件、公开安装名称和记录均未变化。日常安装版未升级。
