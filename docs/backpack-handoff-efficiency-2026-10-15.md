# 重复资源请求与浏览器回传优化

2026-10-15。保持现有选择实现和最终 0.7 门槛，只复测原来的弹簧单文件网页题一次，没有固定英文摘要、指定能力名或重跑其他已通过业务题目。

相较上一候选版本，主 Agent 总 token 从 **103,882 降至 67,053（减少 35.45%）**，主 Agent 加 Jev 从 **156,753 降至 113,777（减少 27.42%）**；总耗时从 **245.415 降至 193.906 秒（减少 20.99%）**。这次重复资源请求和额外模型等待轮次均未出现。更早的中文基线是 164.759 秒，本次仍慢约 29 秒，不能称为整体最快方案。

## 问题与改动

上一轮组合接入已经按当前任务查过补充资源，返回 `none`，但 Agent 又请求最接近的学习模板，最终仍是 `none`。原返回值保留了置信度，却没有说明当前查找已经完成；连接说明还笼统邀请继续找参考资料。

现在仅补充结果解释：当前需求没有补充资源通过原有检查；不要改写同一需求再次查找。指导足够时继续原任务，实际出现新的缺失要求时仍可请求资源；必需参考缺失时明确报告。没有按词义猜测、缓存或屏蔽新需求，没有把 `none` 改成选中，也没有压低门槛。异常、低置信度及敏感输入状态原样保留。所有被选中的完整指导和资源继续返回。

上一轮浏览器工具等待 73.715 秒，记录的实际操作段约 18 秒；差额包含宿主接手、模型/工具间隔与验收回传，而不是浏览器一直在运行。新增的有界等待器在请求出现后立即通知宿主，并用同一文件哈希和请求 ID 绑定观察结果；完成必要交互后先发布结果，再保存展示截图和做统计。请求与结果用原子、不可覆盖的文件发布，旧请求或未知结果不自动重做。提交前另补上过期请求拒绝检查，通过本地回归；没有为这项负向检查重跑网页题。

这部分属于**测试设施和宿主执行方式**。没有把一个新的浏览器服务安装进日常背包，也没有把宿主操作假装成受测 Agent 自带的能力。参照 [Anthropic 的工具组合说明](https://www.anthropic.com/engineering/advanced-tool-use)减少中间往返，保留 [MCP 工具结果语义](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)，不借用外部报告的收益数字。

普通中文题仍要求制作离线单文件 `index.html`，用 k、m 滑块观察 `T=2π√(m/k)`，显示参数和单位，提供重置与配置 JSON 复制，并检查计算及交互。

三列都使用 `gpt-6-astra / xhigh`、CLI `0.163.0-alpha.10.2`。本轮与上一轮用户题和测试 policy 字节相同；初始 70 条分类、公开目录快照及已安装能力名称集相同，使用全新会话、工作区和背包存储。没有复制已连接的包、授权或完成记录。实际模型端身份不可进一步观察；共享 standalone runtime 未做跨历史运行的完整字节冻结。

## 浏览器等待拆分

| 阶段 | 本次时间 |
|---|---:|
| 请求产生到等待器发现 | 0.014 秒 |
| 等待器发现到开始浏览器操作 | 3.982 秒 |
| 浏览器观察、交互及期间宿主往返 | 25.496 秒 |
| 交互完成到发布结果 | 12.636 秒 |
| 发布结果到网关收到 | 0.146 秒 |

文件传递本身没有造成几十秒的等待。仍有约 12.6 秒在观察完成到回执发布之间，受宿主模型/工具调度影响；这次没有消除所有回传开销。总等待已低于 Agent 的 60 秒初始等待，因此没有再唤醒模型做一次 `wait`。浏览器实际操作段没有变快，不能把总等待下降解释为浏览器执行加速。

## 验收与保护

通过实际浏览器控件把 k 调到 80 N/m，周期显示 0.7025 秒；再把 m 调到 4 kg，显示 1.4050 秒。实际剪贴板 JSON 为 k=80、m=4、T=1.4049629462081452，单位正确；重置恢复 k=20、m=1、1.4050 秒。用户剪贴板已恢复。页面通过 localhost 打开且阻断外部请求，未直接测试 `file://`。

受测 Agent 自己在检查通过后写入 `agent_reported/completed`；评估端没有代写使用记录。新接入的公开插件是 `playground`，来源固定为 `anthropics/claude-plugins-official` 的 `8f814f49002ff824e8a9ba43cf96112dc7f5948d`，在测试前已安装名称集中不存在。最终贡献/可移植性检查通过，最终置信度 0.98，门槛 0.7。此结果不代表新增的广泛准确率证据。

205 项相关本地测试通过，无跳过。选择、目录、资源选择和连接实现与上一轮字节相同；新增测试覆盖负向资源结果、新需求仍能正常取资源、异常不误称查完，以及请求/回执绑定、完整检查、过期拒绝、不可重放和分段计时。模拟测试不冒充真实浏览器验证。

日常 6 个受保护配置文件全部保持不变；生命周期 `0.3.70+lifecycle.20261015` 的 112 个文件逐一核对字节相同，市场源仍指向该版本。未覆盖生命周期功能、合并 main 或升级日常连接。专用浏览器标签和预览服务已关闭。

本轮只有一次原网页实测，已知主 Agent＋Jev 合计 **113,777 token**。宿主协调、浏览器控制以及一次未选中浏览器指导的前置调用没有完整用量，属于额外未计量开销，不按零计算。未测费用，不据此推算账单。原始会话、认证副本和选择句柄只留在本地隔离证据中。
