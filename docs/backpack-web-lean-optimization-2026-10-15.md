# 网页任务精简、真实浏览器与自动上报

2026-10-15。只重测原来的弹簧单文件网页题，未重跑其他五道已通过题目。

最终版本在一次连续的原生 Agent 运行中完成发现、接入、页面生成、真实浏览器检查和自动使用上报。耗时 144.600 秒，主 Agent 用量 123,182 token；相对上轮分别下降 49.58% 和 38.42%。这是一个任务的单次结果，不能推广成整体准确率或最佳策略证明。

## 改动与原因

- `connect_market_capability(include_guidance=true)` 可在成功连接后直接返回完整绑定 Skill 和一个 Jev 选择的资源，省去两次单独获取。选择、包完整性、授权范围和最终 0.7 门槛保持原有检查；读取失败保留已连接事实，避免重装。
- 小网页只实现用户要求的输入、结果和操作，不主动添加动画、曲线、预设或额外文档。完整指导和必要的安全、正确性要求仍保留。
- 长操作等待时使用 30–60 秒的异步等待，避免每秒唤醒模型。中间一次续跑出现 1 秒和 20 秒轮询，共五次；每轮都再次输入约 2.2 万 token，产生了可观察的额外消耗。最终运行使用 60 秒初始等待，浏览器 40.270 秒内返回，没有额外轮询。
- 工作完成后由 Agent 自动提交简短使用结果。不能在连接或读取时提前记为完成。最终真实 MCP 回执为 `recorded`，隔离存储中存在 `completed` 使用记录。
- 置信度不足现在报告“适配判断不确定”，避免误称为已确认的运行环境不支持。未放宽门槛，也未删除未选中的目录候选。

模型、推理档位仍为 `gpt-6-astra / xhigh`，CLI 版本相同，单次时限 360 秒。新鲜会话、独立工作区和背包存储；公开目录与初始 70 条分类记录相同。每次排除日常已安装能力。最终仍由背包选到并接入此前未安装的 `playground`，用户题目没有指定能力名。

本轮四次工具调用为准备、连接并读取、浏览器验证、使用上报。主 Agent 本轮只写一个 HTML 文件，没有另外启动命令来探测浏览器或编写模拟浏览器框架。

比较存在明确条件差异：原始中文网页题保持不变，但为了稳定后续性能对照，最终两轮固定使用上轮记录的英文功能摘要和通用搜索词；摘要不含能力或厂商名称。真实浏览器工具为本次宿主验证环境新增，原先只有模拟检查。以上是组合方案的观测结果，不是只改变一个因素的严格 A/B。

## 真实验证证据

宿主使用 Codex 内置真实浏览器，打开与 Agent 输出字节一致的新页面。Agent 调用验证工具等待结果后才报告使用完成；宿主不代写使用记录。

- 默认 `k=20 N/m, m=1 kg`，显示 `T=1.4050 s`。
- 真实拖动刚度至 `80 N/m`，显示 `0.7025 s`；JSON 为 `0.7024814731040726`。
- 再真实拖动质量至 `4 kg`，显示 `1.4050 s`。
- 点击复制按钮后，实际浏览器剪贴板得到 `k=80, m=4, T=1.4049629462081452`，三个单位正确。
- 点击重置恢复默认参数；无浏览器错误或警告。页面未被验证端修改，测试前剪贴板恢复。

浏览器使用阻断外部资源请求的 localhost 预览；检查页面没有外部资源引用，但**没有直接测试 `file://` 打开方式**。浏览器桥接器仅是基准测试设施，不是这次为正式背包新增的浏览器能力。控制浏览器的宿主 Agent token 不可观测，属于额外未计量开销，不按零计算。

## 失败、修复和消耗保留

没有只保留最好的一次：

| 本轮过程 | 结果 | 原生运行时间 | 已知主 Agent + Jev token |
|---|---|---:|---:|
| 自动生成中文需求摘要 | 最终选择置信度 0.62，低于 0.7；未产生网页 | 57.977 秒 | 176,781 |
| 固定上轮摘要，路径接口修复前 | 网页已生成；绝对路径被验证接口提前拒绝；Agent 自动记录失败 | 154.334 秒 | 192,259 |
| 同一会话只补未完成验证与上报 | 浏览器通过并自动记录完成，保留失败历史；短轮询浪费 token | 103.545 秒 | 新增 177,165 |
| 路径与等待修复后的新鲜完整运行 | 一次通过 | 144.600 秒 | 169,596 |

另有四次低成本 Jev 单级诊断，共 5,964 token，包括一个合成的缺少必需运行条件的反例。没有帮助的评分措辞修改已撤回。中文原题直接提交得到 0.68，自动生成中文摘要得到 0.62，上轮英文摘要为 0.72；**同义表述的路由稳定性仍未解决**。这些数值不是普遍的中英文优劣证明。

本轮全部尝试与诊断合计 **721,765 已知 token**，不含宿主协调和浏览器控制。两段续跑的原生累计用量取最终会话累计值，未重复相加两次累计回执。续跑的运行时间合计为 257.879 秒，若包含中间人工排查间隔，墙钟为 366.014 秒。上述失败过程不能与最终一轮混为一次成功，也不能合并成统计准确率。

## 验证与边界

181 项相关本地测试通过；最后的等待说明调整又运行了其中 13 项针对性测试。项目必需文件、目录 JSON 和 diff 检查通过。真实运行与本地测试分别记账。

六个日常配置文件和公开安装清单保持不变。预览服务已核对进程后停止，任务创建的浏览器标签页已关闭，隔离数据保留。源代码在任务分支；**没有更新日常安装版或合并主分支**。独立运行时依赖沿用同一路径，但它是共享脏工作树，没有冻结全部字节，因此不能宣称完全隔离的运行时 A/B。

[机器可读结果](../benchmarks/results/backpack-web-lean-comparison-2026-10-15.json)。原始会话、认证副本、选择句柄、安装清单和完整运行日志仅保存在本地隔离证据目录，未进入仓库。

方法参考：[OpenAI 延迟优化](https://developers.openai.com/api/docs/guides/latency-optimization)说明减少生成量和请求次数有助于降低延迟；[Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)用于区分缓存输入与总用量。本报告采用实际计数，不把缓存输入重复加入总 token，也不从 token 数推算未观测的金额。
