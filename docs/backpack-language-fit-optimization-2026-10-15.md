# 中文与混合语言的最终能力判断

2026-10-15。保留精简流程和最终 0.7 门槛，只复测原来的弹簧单文件网页题，没有重跑其他五道已通过题目。改动在任务分支，尚未合并或升级日常安装版。

## 结果与适用范围

同一完整指导、同一批 10 个冻结输入，旧判断放行 2/6 个有效需求，新判断放行 6/6；两者都没有放行 4 个不适合的反例。新鲜原生 Agent 自行写中文需求，成功发现、接入此前未安装的公开插件并完成网页，真实浏览器检查和自动使用上报通过。

改善主要在有效需求召回。本次完整任务没有进一步降低时间或总 token：164.759 秒、169,740 已知 token，上次固定英文摘要的成功运行是 144.600 秒、169,596 token。一个任务、一次运行不能证明整体准确率或速度优势。

## 原因和最小改动

旧最终问题把“指导能提供帮助”“当前环境能使用”“用户输出约束”放在一个选择里判断。保留完整指导时，相同用途的中文描述会在 0.7 附近反复拒绝。本轮固定样本里，原中文题得 0.66，上轮生成的中文摘要得 0.56，两种混合语言分别为 0.74、0.70；不能把这些分数解释为实际正确率。

在同一个 `jev run` 请求中分别询问：

1. 指导中的方法或资源是否直接帮助所需的产物。通用方法可以用于新的主题，用户决定产物形式。
2. 是否至少有一项相关方法能用本地文件和语言运行时执行，且不依赖缺失的必需原生 Agent、Hook、产品 CLI、登录或账户服务。

两项都回答 yes，且每项置信度都达到 `max(0.7, 配置门槛)` 才放行。最终分数取两者较低值，不取平均、不转成概率、不降低更高的配置门槛。缺项、非有限数、未知答案或供应商错误不能放行；不自动降级回旧问题。

只改变 `jev-cli` 的单个完整插件指导最终判断。目录仍两至三层、前宽后严，完整候选、待分类候选和完整指导内容保留；主 Agent 调用轮数不增加。旧 `typesafe-http` 适配器继续使用原单问题协议，本次多问题改善没有在该协议上验证。此次没有重新设计 Skill 或 MCP 的最终判断。

方法依据：[TypeSafe primitives](https://docs.typesafe.ai/primitives)建议把不同判断拆成独立问题，支持一次请求共享同一状态；[置信度定义](https://docs.typesafe.ai/confidence)区分选择置信度和原始概率，本次仍按置信度比较 0.7；[Agent 工具评估建议](https://www.anthropic.com/engineering/writing-tools-for-agents)用于约束真实任务、保留样本和成本计量。结果以实际回执为准。

## 先做低成本对照

冻结 [10 个输入](../benchmarks/market-blind/language-fit-cases.json)：开发样本 3 个（2 正、1 反），保留样本 7 个（4 正、3 反）。新问题在保留样本运行前已冻结，之后未按结果修改。每种方法各 10 次请求，只调用最终判断，不安装插件、不生成业务产物。

| 指标 | 旧单问题 | 新双问题、单请求 |
|---|---:|---:|
| 有效需求被放行 | 2/6（33.3%） | 6/6（100%） |
| 不适合需求被放行 | 0/4 | 0/4 |
| 已放行项的精确率 | 2/2 | 6/6 |
| 全部匹配判定符合预期 | 6/10 | 10/10 |
| 保留样本符合预期 | 5/7 | 7/7 |
| 平均最终判断时间 | 0.522 秒 | 0.540 秒 |
| 10 次合计 token | 14,178 | 15,419 |

每次平均多约 124 token（8.75%），多约 0.018 秒，HTTP 请求次数不变。前后串行观察的时间不是统计性能结论。将不确定结果计为未召回，未排除失败或只统计已选出的项。

实现接入后另做 3 次低成本检查，合计 3,486 token：原中文需求通过、必需服务反例未放行、补充的“有用但依赖缺失专有引擎”反例也未放行。最后一个反例的维度答案并不理想（贡献 no/0.48、可用 yes/0.74），最终仍拒绝；因此不能宣称维度解释始终正确，或 0.98 分数等于 98% 准确率。该补充反例单独记账，没有补入原 10 题改善分母。

## 原网页需求的真实运行

模型与推理档位保持 `gpt-6-astra / xhigh`。原中文用户题逐字不变；不指定能力名，不提供固定英文摘要或固定搜索。Agent 自己写出中文功能需求，并采用通用英文搜索词 `interactive educational webpage`。这符合“不固定英文摘要”，不是把整个检索强制改成全中文。

使用同一公开目录快照和初始 70 条分类记录、独立会话/存储/工作区。实际目录含 315 个插件候选，所选类别保留 135 个并携带待分类项。Agent 选中此前未安装的 `playground`，包固定为 `anthropics/claude-plugins-official` 的 `8f814f49002ff824e8a9ba43cf96112dc7f5948d`。最终贡献 yes/1.00、可用 yes/0.98，最低门槛 0.7。

本次总 token 增加 0.085%，时间增加 13.94%。其中背包准备 8.338 秒、连接并返回指导/资源 1.498 秒、真实浏览器等待 50.768 秒、上报 0.010 秒，其余时间 104.145 秒。浏览器实际操作记录为 25.809 秒，工具等待还包含宿主接手、读取及传回验收的间隔。不能把增加的等待都归因于能力选择。未增加短轮询、模拟浏览器框架或额外业务功能。

上次自行生成中文需求的运行在最终 0.62 时拒绝，57.977 秒、176,781 已知 token，未产出网页；本次完成。失败运行更快不能当作成功路径的性能优势。CLI 从 `0.162.0-alpha.17.2` 更新为 `0.163.0-alpha.10.2`，且取消了固定摘要，因此完整运行不是严格单因素性能 A/B。共享 standalone runtime 沿用同一路径，没有完全冻结其字节。

真实浏览器打开与产物字节一致的 localhost 页面，阻断外部请求。实际拖动两种滑块后，三组独立公式核对为：`40 N/m, 1 kg → 0.993 s`；`110 N/m, 1 kg → 0.599 s`；`110 N/m, 3.2 kg → 1.072 s`。真实剪贴板 JSON 与第三组参数/未舍入周期一致，重置恢复第一组，无控制台错误。没有直接验证 `file://` 打开方式。

Agent 收到浏览器通过回执后自行上报；工具返回 `recorded`，隔离 `skill-usage.json` 存在 `agent_reported/completed`。评估端没有补写记录。浏览器桥接器属于测试设施，不是正式背包的新能力。

## 总消耗、验证和保存范围

本轮只有一次原生网页任务，另有 23 次低成本最终判断；包含原生流程的 10 次 Jev，总计 33 次 Jev 请求、**202,823 已知 token**。宿主协调和浏览器控制 Agent token 为 `unobservable`，属于额外未计量成本，不计成零。缓存输入和推理输出子集不重复加入总量。

188 项相关本地测试通过，无跳过。第一次用系统默认临时目录运行时，路径安全测试识别到 macOS `/var` 的符号链接；补上既有 standalone runtime 并使用规范化 `/private/tmp` 后，完整 188 项通过，没有为此改变安全检查。项目必需文件、目录 JSON 和 diff 检查通过。

六个日常配置文件和公开安装清单逐项核对未变；预览服务与专用浏览器标签页已关闭，用户剪贴板已恢复，隔离证据保留。未改其他工作树或日常插件安装。完整会话、认证副本和选择句柄不上传；公开结果仅含无秘密的样本、计数和必要来源。
